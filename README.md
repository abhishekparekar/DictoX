# DictoX Marketing Website

Official website for **DictoX Marketing** — a performance marketing and customer acquisition agency helping ambitious brands scale profitably through high-converting funnels, targeted media buying, and AI-driven growth strategies.

## 🚀 Tech Stack

- **Framework**: [Vite](https://vitejs.dev/) + Modern Vanilla JavaScript / Components
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Glassmorphism & Animations
- **Icons**: Lucide Icons
- **Fonts**: Inter & Outfit

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/abhishekparekar/DictoX.git

# Navigate into the project directory
cd DictoX

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:3000` (or the port specified in terminal) in your browser.

### Building for Production

```bash
npm run build
```

The production-ready assets will be generated in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```
